# Schulrecht Hamburg: Lerntrainer

Hamburgisches Schulgesetz zum Hören und Üben für Lehrkräfte im Vorbereitungsdienst in Hamburg: Hörbuch (synthetische Stimmen), Kurzfassungen, Beispielfälle, Übungsmodi, offline nutzbar.

Live: https://herrohlsen.github.io/schulrecht-hamburg/

Quelle: Hamburgisches Schulgesetz in der Ausgabe der Behörde für Schule und Berufsbildung (Juni 2023). Kurzfassungen und Fälle wurden mit Claude am Gesetzestext erstellt. Lernhilfen, keine Rechtsberatung.
